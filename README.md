# 💼 MoneyMantra – Your Smart Guide to Wealth & Wisdom

MoneyMantra is a modern finance web application designed to simplify personal finance for everyone.  
It provides easy-to-understand tools, calculators, and learning resources that help users make smarter financial decisions.  
This project was created as a **capstone project** to demonstrate skills in frontend development, UI design, and financial tool implementation.

## 📌 Features

### 🔹 1. Home Page (Hero Section)
- Clean, modern design introducing MoneyMantra  
- Highlights the core purpose: *Your Smart Guide to Wealth & Wisdom*  
- Finance-themed visuals and branding  

### 🔹 2. Tools Section (Main Feature Area)
Includes practical tools inspired by modern finance platforms like Groww & Zerodha:

#### **A. SIP Calculator**
- Users enter monthly investment, interest rate, and duration  
- Calculates total investment, returns, and maturity value  
- Real-time computation using JavaScript  
- Interactive pie-chart built using **Chart.js**

#### **B. Expense Tracker**
- Add daily or monthly expenses  
- Automatically updates total expenditure  
- Simple, clean UI for tracking money flow  

#### **C. Budget Planner**
- Enter income and planned savings  
- Calculates available spending budget  
- Helps users plan monthly finances efficiently  

### 🔹 3. Learn Section
- Overview of beginner-friendly finance topics  
- Topics include:  
  - Stock Market Basics  
  - Mutual Funds  
  - Budgeting & Savings  
  - Personal Finance Tips  

### 🔹 4. About Page
- Describes the mission of MoneyMantra  
- Includes: Who we are, mission, what we offer, project story  
- Follows a clean layout with images and cards  

### 🔹 5. Contact Page
- Contact form (Name, Email, Subject, Message)  
- Displays support email, phone number, and address  
- Social media links  
- Embedded Google Map (Rishihood University)

### 🔹 6. Navigation Bar + Multi-Page Structure
- Fully connected pages:
  - Home (index.html)  
  - Tools (tools.html)  
  - About (about.html)  
  - Contact (contact.html)  

### 🔹 7. Responsive Design
- Pages adjust for mobile and tablet  
- Flexbox & responsive units used throughout the layout
